## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск FastAPI

```bash
uvicorn fastapi_app:app --reload
```

После запуска документация Swagger доступна по адресу `/docs`.

## Запуск Flask

```bash
python flask_app.py
```

Страница с таблицей данных доступна по адресу `/table`.

## Тесты

python -m unittest -v
